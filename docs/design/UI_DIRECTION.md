# UI_DIRECTION.md

# Rangkul Cerita

## UI Direction & Creative Principles

Version: 1.0

## Purpose

Dokumen ini menjadi arah visual utama untuk seluruh pengembangan UI
Rangkul Cerita.

> Membantu pengguna merasa cukup aman untuk memulai percakapan dengan
> dirinya sendiri.

## Core Experience

Website ini adalah **a calm guided emotional journey**.

Homepage mengarahkan pengguna ke Check-in → Reflection → Next Step →
Journal/Human Support.

## Design Personality

-   Calm
-   Warm
-   Honest
-   Professional

## Visual Principles

-   Remove Noise
-   Typography Before Decoration
-   White Space Creates Trust
-   One Primary Action

## Icon Philosophy

Gunakan icon hanya bila benar-benar membantu recognition.

## Card Philosophy

Card bukan layout default.

## Border Philosophy

Whitespace → Background → Elevation → Border.

## Typography Philosophy

Hierarchy dibangun oleh typography.

## Color Philosophy

Hijau adalah identitas, bukan dekorasi.

## Motion

Fade, slide ringan, accordion.

## Progressive Disclosure

Tampilkan informasi sesuai langkah pengguna.
