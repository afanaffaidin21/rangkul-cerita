## Layout

-   Max width 1200px
-   Reading width 720--820px

## Typography

Display → H1 → H2 → H3 → Body → Caption

## Section Rhythm

Hero (Large), Trust (Small), Check-in (Large), Information (Medium),
Feature (Large), FAQ (Medium), CTA (Large).

## Icons

Fungsional, bukan dekoratif.

## CTA

## Human Support

LOW secondary, ELEVATED prominent, HIGH primary, IMMINENT
emergency-first.

## Anti-Patterns

-   Terlalu banyak card
-   Terlalu banyak icon
-   Dua CTA utama
-   Hero padat
