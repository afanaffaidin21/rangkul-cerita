# Rangkul Cerita — Next.js Edition

Ruang digital aman untuk check-in emosi, jurnal terpandu, dan informasi bantuan kesehatan mental untuk anak muda Indonesia.

## Run Locally

**Prerequisites:** Node.js (v18+)

1. Install dependencies:
   ```bash
   npm install
   ```

2. Konfigurasi API Key di `.env.local` or `.env`:
   ```env
   GEMINI_API_KEY="AIzaSy..."
   ```

3. Jalankan server pengembangan (Next.js):
   ```bash
   npm run dev
   ```

4. Buka di browser: `http://localhost:3000`
